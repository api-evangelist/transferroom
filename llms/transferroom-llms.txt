# TransferRoom

> TransferRoom is football's real-time transfer marketplace, connecting clubs, agents and players to buy, sell and loan players and to recruit head coaches. Its API delivers verified, real-time market intelligence — Expected Transfer Value (xTV) benchmarks, player availability and deal-viability signals, contract-expiry and salary data, agent/coach representation, and head-coach ratings — as JSON that clubs integrate directly into their BI environments (SQL databases, dashboards, spreadsheets and code notebooks). Trusted by 800+ clubs across 130 leagues and 500+ agencies, covering 130,000+ players and 7,000+ head coaches, and powering 7,500+ transfer deals.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public TransferRoom surface. TransferRoom's API is sales-gated: technical reference (endpoints, authentication, base URL) is provided to clubs on engagement and is not published publicly, so no OpenAPI/Swagger, SDKs, or public /.well-known documents were found.
